Add a shortcut on iPhone

Every shortcut opens through Apple's official iCloud flow, so you can review it before adding it.

01
Open SettingsGo to Shortcuts → Advanced and allow untrusted shortcuts if iOS asks.
02
Tap Get ShortcutReview the actions on the official iCloud page, then tap Add Shortcut.
03
Run itFind it in the Shortcuts app, Home Screen, or Siri.
